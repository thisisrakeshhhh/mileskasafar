# Miles Ka Safar MERN

JavaScript-only MERN travel website inspired by the sales flow of `bookoftrips.in`.

## Structure

- `client/`: React + Vite frontend
- `server/`: Express + MongoDB API

## Run

```bash
npm --prefix client install
npm --prefix server install
npm run dev:client
npm run dev:server
```

## Notes

- This is an inspired rebuild, not a literal copy of the reference site.
- The frontend is styled to follow a similar travel-sales funnel: hero inquiry form, trust stats, destinations, package cards, and expert CTA.
